# UnEarthed

A crowdsourced repo of gift ideas, browsable by audience and price point.
CodePath WEB103 — Unit 1 Lab, Part 1.

## Stack

- **Server:** Node.js + Express (serves the gift data and the static build)
- **Client:** vanilla HTML/CSS/JavaScript, bundled with Vite (no frontend framework)

## Structure

```
unearthed
├─ client            # frontend source
│  ├─ public         # copied to the build as-is (pages, scripts, css, images)
│  │  ├─ scripts     # header.js, gifts.js, gift.js
│  │  ├─ images
│  │  ├─ gift.html
│  │  ├─ 404.html
│  │  └─ style.css
│  ├─ index.html
│  └─ vite.config.js # builds into ../server/public, proxies /gifts to :3001
└─ server
   ├─ data/gifts.js    # the gift data
   ├─ routes/gifts.js  # GET /gifts and GET /gifts/:giftId
   ├─ public           # build output (generated by `npm run build`)
   └─ server.js
```

## Running it

Two terminals.

```bash
# terminal 1 — API on http://localhost:3001
cd server
npm install
npm start

# terminal 2 — frontend on http://localhost:5173
cd client
npm install
npm run build   # needed for the gift detail and 404 pages
npm run dev
```

Open http://localhost:5173.

## Routes

| Route | What it does |
| --- | --- |
| `GET /` | API banner |
| `GET /gifts` | all gifts, as JSON |
| `GET /gifts/:giftId` | serves the gift detail page |
| anything else | serves the 404 page |

## Features

- [x] HTML, CSS and JavaScript only — no frontend framework
- [x] Title and logo
- [x] List of gifts with name, price point, audience and image
- [x] Detail view per gift with every field
- [x] 404 page for undefined routes
